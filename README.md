# OpenGD77 Satellite Updater for Android

Первый рабочий исходный прототип Android-приложения для обновления Keps/TLE в TYT MD-9600 с OpenGD77/OpenGD77RUS через USB OTG.

## Совместимость

- minSdk 23 = Android 6.0
- Java 8, обычные Android Views (без Compose)
- USB Host API / UsbManager, без стороннего USB-драйвера
- VID:PID OpenGD77 `1FC9:0094`
- 115200 8N1, CDC ACM

## Источники TLE

В UI предустановлены:

- `https://celestrak.org/NORAD/elements/gp.php?GROUP=amateur&FORMAT=tle`
- `https://r4uab.ru/satonline.txt`

Также есть импорт локального текстового TLE-файла — это полезный резервный путь для очень старых Android, если системное хранилище сертификатов не принимает современный HTTPS-сертификат сайта.

## Что уже реализовано

1. Парсер пользовательского `Satellites.txt`.
2. Парсер стандартных 3-line TLE наборов, сопоставление по NORAD Catalog Number.
3. Точный OpenGD77 encoder 40-байтной орбитальной части.
4. 100-байтная запись спутника с частотами, CTCSS + ArmCTCSS и APRS path.
5. Воспроизведение float32-округления CPS для частот.
6. Поиск TLV ID 3 в Additional Settings.
7. Безопасный Read-Modify-Write двух 4KB FLASH-секторов от `0x20000`.
8. OpenGD77 R/X/C протокол и проверка radioType=5 (MD-9600).
9. USB CDC через штатный Android UsbManager.
10. Unit test ISS, сравнивающий 100 байт с реальной записью CPS 2025.2.18.3 из кодплага 24.09.2026.

## Сборка APK

GitHub Actions автоматически запускает unit-тесты и собирает debug APK при push в `main`.

## Важная оговорка

Проект сформирован и алгоритм/fixtures проверены по реальным файлам, но USB-часть ещё не проверена физически на MD-9600 с Android. Первую проверку на телефоне рекомендуется начать с кнопки **«Подключить MD-9600 и прочитать»**, не нажимая запись, и сверить лог.

## v0.6.0 — локальный редактор

После чтения MD-9600 откройте канал, контакт или зону и нажмите «Изменить».
В разделе «DMR ID и позывной» доступна отдельная кнопка «Изменить».
Редактируются существующие записи: общие параметры каналов и FM/DMR,
DMR ID/позывной, контакты DMR/DTMF, имена и состав зон (до 80 каналов).
Добавление/удаление записей, правка VFO, APRS, координат, списков групп и
сканирования пока не реализованы. Остальные разделы доступны для просмотра.

Каждая принятая правка атомарно сохраняется в приватном каталоге приложения.
«Проект» позволяет экспортировать/импортировать `.ogcproj`, отменять последние
20 операций текущей сессии, восстановить исходное чтение и видеть число
изменённых байтов по блокам. Исходная и рабочая копии входят в файл проекта;
контрольная сумма и размеры блоков проверяются при открытии.
`.ogcproj` — собственный формат Android-редактора, не `.ogd` Windows CPS.
Экспортируйте проект за пределы приложения перед его удалением.

Редактор не отправляет изменения в радиостанцию. Существующий отдельный модуль
обновления спутников не связан с проектом codeplug. Неизменённые поля и
неизвестные биты сохраняются в исходном виде. В интерфейсе скрывается неактивный
блок FM/DMR; его байты сохраняются при переключении режима.
