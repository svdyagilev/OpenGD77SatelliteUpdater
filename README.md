# OpenGD77 Satellite Updater for Android

Первый рабочий исходный прототип Android-приложения для обновления Keps/TLE в TYT MD-9600 с OpenGD77/OpenGD77RUS через USB OTG.

## Совместимость

- minSdk 23 = Android 6.0
- Java 8, обычные Android Views (без Compose)
- USB Host API / UsbManager, без стороннего USB-драйвера
- VID:PID OpenGD77 `1FC9:0094`
- 115200 8N1, CDC ACM

## Источники TLE

В UI предустановлены:

- `https://celestrak.org/NORAD/elements/gp.php?GROUP=amateur&FORMAT=tle`
- `https://r4uab.ru/satonline.txt`

Также есть импорт локального текстового TLE-файла — это полезный резервный путь для очень старых Android, если системное хранилище сертификатов не принимает современный HTTPS-сертификат сайта.

## Что уже реализовано

1. Парсер пользовательского `Satellites.txt`.
2. Парсер стандартных 3-line TLE наборов, сопоставление по NORAD Catalog Number.
3. Точный OpenGD77 encoder 40-байтной орбитальной части.
4. 100-байтная запись спутника с частотами, CTCSS + ArmCTCSS и APRS path.
5. Воспроизведение float32-округления CPS для частот.
6. Поиск TLV ID 3 в Additional Settings.
7. Безопасный Read-Modify-Write двух 4KB FLASH-секторов от `0x20000`.
8. OpenGD77 R/X/C протокол и проверка radioType=5 (MD-9600).
9. USB CDC через штатный Android UsbManager.
10. Unit test ISS, сравнивающий 100 байт с реальной записью CPS 2025.2.18.3 из кодплага 24.09.2026.

## Сборка APK

GitHub Actions автоматически запускает unit-тесты и собирает debug APK при push в `main`.

## Важная оговорка

Проект сформирован и алгоритм/fixtures проверены по реальным файлам, но USB-часть ещё не проверена физически на MD-9600 с Android. Первую проверку на телефоне рекомендуется начать с кнопки **«Подключить MD-9600 и прочитать»**, не нажимая запись, и сверить лог.

## v0.8.2 — чтение и редактирование базы позывных

- «Прочитать базу из рации» загружает существующую базу MD-9600, показывает число записей и позволяет искать по DMR ID или тексту.
- Нажатие на запись открывает редактор: можно изменить ID и текст либо удалить запись; «Добавить запись вручную» создаёт новую.
- Редактор изменяет только подготовленный список в приложении. Запись в рацию остаётся отдельным действием с прежней резервной копией, проверкой секторов и read-back.
- Чтение поддерживает только проверенные регионы памяти и форматы записей; неизвестный заголовок, неверный счётчик или несортированные/повторные ID отклоняются.

Автоматические тесты и APK собираются GitHub Actions для ветки этой версии. Чтение и запись базы позывных в физическую MD-9600 ещё требуют аппаратной проверки.


## v0.6.0 — локальный редактор

После чтения MD-9600 откройте канал, контакт или зону и нажмите «Изменить».
В разделе «DMR ID и позывной» доступна отдельная кнопка «Изменить».
Редактируются существующие записи: общие параметры каналов и FM/DMR,
DMR ID/позывной, контакты DMR/DTMF, имена и состав зон (до 80 каналов).
Добавление/удаление записей, правка VFO, APRS, координат, списков групп и
сканирования пока не реализованы. Остальные разделы доступны для просмотра.

Каждая принятая правка атомарно сохраняется в приватном каталоге приложения.
«Проект» позволяет экспортировать/импортировать `.ogcproj`, отменять последние
20 операций текущей сессии, восстановить исходное чтение и видеть число
изменённых байтов по блокам. Исходная и рабочая копии входят в файл проекта;
контрольная сумма и размеры блоков проверяются при открытии.
`.ogcproj` — собственный формат Android-редактора, не `.ogd` Windows CPS.
Экспортируйте проект за пределы приложения перед его удалением.

Редактор не отправляет изменения в радиостанцию. Существующий отдельный модуль
обновления спутников не связан с проектом codeplug. Неизменённые поля и
неизвестные биты сохраняются в исходном виде. В интерфейсе скрывается неактивный
блок FM/DMR; его байты сохраняются при переключении режима.

## v0.6.1 — выборочная запись codeplug

В редакторе доступна кнопка «Записать»: DMR ID/позывной, каналы, контакты DMR,
контакты DTMF и зоны. Можно выбрать несколько разделов. Только существующие записи.
Перед записью выполняется сверка исходного проекта с рацией и сохраняется резервная
копия полных секторов. После записи каждый сектор проверяется повторным чтением.
Невыбранные изменения остаются в проекте. При ошибке нет автоматического повтора;
нужно сохранить резервную копию, перезапустить и заново прочитать рацию.

Подробности протокола, восстановления и ограничений: [docs/CODEPLUG_WRITE.md](docs/CODEPLUG_WRITE.md).
Проверка на физической MD-9600 не подменяется автоматическими тестами.

## v0.6.2 — следующие разделы редактора

- Загрузочный экран: режим изображения/текста и две строки до 16 символов.
- Списки групп приёма: имя до 15 символов и упорядоченный состав до 32 существующих
  DMR-контактов; выбор по имени или номерам. Пустой состав сохраняет саму группу.
- APRS: имя, SSID, маршрут из двух узлов, комментарий ASCII до 23 символов, частота
  (0 — частота канала), скорость, фиксированные координаты и QSY.

Эти разделы отдельно выбираются на экране записи. Создание и удаление записей
пока не реализованы. Заставка не изменяет пароль, быстрые клавиши и VFO. APRS
сохраняет значок, служебные байты и неотредактированные флаги.

Пользователь подтвердил запись и повторное чтение в v0.6.1: каналы, зоны, контакты
DMR, DMR ID и позывной. DTMF не проверены из-за пустого списка. Новые разделы
v0.6.2 проверены автоматическими тестами, аппаратная проверка предстоит.

Для проверки: изменить одну строку заставки / имя группы / комментарий APRS,
записать соответствующий раздел, после перезагрузки прочитать рацию заново и
сравнить значения. APK распространяется в ZIP-архиве.


## v0.6.3 — создание записей

В разделах контактов DMR, контактов DTMF, каналов и зон появилась кнопка
«Добавить». Поддерживаются пустые списки, русский текст, аналоговые и цифровые
каналы, выбор каналов зоны по именам. Отмена формы не создаёт запись.
Существующие записи не перенумеровываются; используется первое свободное место.
Лимиты: 1024 DMR-контакта, 63 DTMF-контакта, 1024 канала, 250 зон по 80 каналов.

Новые записи автосохраняются, экспортируются в .ogcproj, поддерживают отмену
и записываются через прежний экран выбора разделов. При ссылке на новую запись
нужно выбрать оба раздела (например, канал и его новый DMR-контакт).
Перед записью сверяются также исходные связанные блоки радиостанции.

После смены прошивки сначала заново прочитайте радиостанцию. Аппаратная проверка
создания записей предстоит; прежнее редактирование проверено пользователем.


## v0.6.4 — выбор субтонов и общий вызов

Субтоны RX/TX при создании и редактировании канала выбираются из таблицы:
«Нет», 50 CTCSS, 83 DCS с обычной (N) или инверсной (I) полярностью.
Таблицы соответствуют TRX_CTCSSTones и TRX_DCSCodes OpenGD77; прочитанные
значения вне таблиц сохраняются, пока пользователь не выберет замену.
При выборе типа DMR-контакта «Общий» ID автоматически становится 16777215,
поле блокируется. Возврат к групповому/индивидуальному типу восстанавливает
предыдущее введённое значение. Это действует и для создания, и для редактирования.


## v0.7.0 — списки, удаление и дополнительные настройки

- Создание, редактирование и удаление каналов, зон, контактов DMR/DTMF,
  групп приёма, списков сканирования и APRS.
- Удаление очищает ссылки в каналах (включая скрытые поля другого режима),
  VFO, зонах, списках, группах и быстрых командах DMR. Номера не сдвигаются.
  Перед удалением показаны затронутые разделы; доступна отмена через «Проект».
- Редактирование VFO A/B, координат канала, символа APRS, настроек DTMF,
  чувствительности VOX и границ частот codeplug.
- Приоритеты списка сканирования: нет, текущий канал или выбранный канал.
  Поддержка сканирования таких списков и старых DTMF-функций зависит от прошивки.
  Поля геопозиции RUS не используются как старые ссылки каналов на scan list.
- Сведения HW/FW/CPU, серийный номер и неподтверждённые служебные флаги
  остаются только для чтения. Спутники обновляются прежним отдельным экраном.
- Выборочная запись проверяет ссылки на итоговом наборе выбранных разделов.
  Заставка/VFO и DMR ID/VOX имеют раздельные диапазоны записи и исходные образы.

Настройка границ меняет только codeplug, а не аппаратные возможности или
ограничения прошивки. Версия 0.7.0 требует аппаратной проверки новых операций.


## v0.7.1 — создание отсутствующего блока спутников

Если заголовок OpenGD77 v1 корректен, цепочка TLV заканчивается FF/FF,
а оставшаяся часть прочитанной области 0x2000 полностью стёрта, обновление
может создать Satellite TLV ID 3 из Satellites.txt и пригодных TLE.
Перед записью показан отдельный запрос создания списка; backup, повторное
чтение и полный read-back остаются обязательными. За новым блоком сохраняется
стёртый терминатор. При повреждённой цепочке, неизвестных данных в хвосте
или недостатке места запись запрещена. Существующий спутниковый блок по-прежнему
обновляется только по орбитальным байтам, без изменения состава и частот.
Исправление воспроизводит структуру проекта MD9600-20260930-153401: блоки
1/0x400 и 2/0x200, затем стёртая память с +0x61C. Новый блок заканчивается
на +0xFFB, поэтому для этого образа меняется только FLASH-сектор 0x20.


## v0.8.0 — база позывных DMR

- Отдельный экран «База позывных DMR» на главном экране.
- Загрузка официального RadioID CSV по HTTPS, импорт CSV UTF-8/Windows-1251,
  сохранение последнего исходного CSV для повторной фильтрации без сети.
- Фильтр по одному или нескольким префиксам ID (по умолчанию 401),
  имя/фамилия/город/область/страна, разделитель пробел/точка, 16–48 символов.
  По умолчанию выбрано 48 символов; полный текст остаётся в предпросмотре,
  а возможная обрезка радиополя явно показана стрелкой.
- Предпросмотр именно записываемого текста и поиск; показаны до 200 совпадений,
  запись использует весь подготовленный список. Кириллица транслитерируется,
  диакритика удаляется, остальные неподдерживаемые знаки становятся точками.
- ID сортируются, повторные ID объединяются (остаётся первая строка),
  некорректные строки подсчитываются, переполнение запрещено.
- Замена или явная очистка базы с отдельным подтверждением. Проверяется модель MD-9600, Radio Info v3/v4 и идентификатор FLASH 16 МБ
  0x4018, если прошивка его сообщает. Обычный маркер отсутствующих полей
  RUS v4 принимается с ограничением записи двумя документированными диапазонами.
- Перед записью сохраняется ZIP всех затрагиваемых секторов (до/после),
  доступен экспорт предыдущих резервных копий. Повторное чтение до записи,
  проверка каждого записанного сектора. При записи нескольких секторов
  заголовок временно отключается и публикуется последним; затем перезагрузка.
- Изменения codeplug, спутники и голосовые подсказки не входят в план записи.

Формат, границы и источники: docs/CALLSIGN_DATABASE.md. Аппаратная проверка
нового модуля пользователем предстоит; создание/обновление спутников v0.7.1
и редактирование codeplug подтверждены пользователем.
