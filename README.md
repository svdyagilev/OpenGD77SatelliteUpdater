# OpenGD77 Satellite Updater for Android

## Версии приложения

- **Проверенная версия: 0.8.10**, `main`, versionCode 37. Пользователь подтвердил работу приложения и загрузку заставки на своей рации.
- **Кандидат: 0.8.13**, `feature/presets-ogd`, versionCode 40. Изменения ожидают проверки на телефоне и рации.
- [Единая карта версий и сборок](VERSIONING.md). APK находятся в [Releases](https://github.com/svdyagilev/OpenGD77SatelliteUpdater/releases); временные сборки — в Actions.

Первый рабочий исходный прототип Android-приложения для обновления Keps/TLE в TYT MD-9600 с OpenGD77/OpenGD77RUS через USB OTG.

## Совместимость

- minSdk 23 = Android 6.0
- Java 8, обычные Android Views (без Compose)
- USB Host API / UsbManager, без стороннего USB-драйвера
- VID:PID OpenGD77 `1FC9:0094`
- 115200 8N1, CDC ACM

## Источники TLE

В UI предустановлены:

- `https://celestrak.org/NORAD/elements/gp.php?GROUP=amateur&FORMAT=tle`
- `https://r4uab.ru/satonline.txt`

Также есть импорт локального текстового TLE-файла — это полезный резервный путь для очень старых Android, если системное хранилище сертификатов не принимает современный HTTPS-сертификат сайта.

## Что уже реализовано

1. Парсер пользовательского `Satellites.txt`.
2. Парсер стандартных 3-line TLE наборов, сопоставление по NORAD Catalog Number.
3. Точный OpenGD77 encoder 40-байтной орбитальной части.
4. 100-байтная запись спутника с частотами, CTCSS + ArmCTCSS и APRS path.
5. Воспроизведение float32-округления CPS для частот.
6. Поиск TLV ID 3 в Additional Settings.
7. Безопасный Read-Modify-Write двух 4KB FLASH-секторов от `0x20000`.
8. OpenGD77 R/X/C протокол и проверка radioType=5 (MD-9600).
9. USB CDC через штатный Android UsbManager.
10. Unit test ISS, сравнивающий 100 байт с реальной записью CPS 2025.2.18.3 из кодплага 24.09.2026.

Загрузка базы позывных, чтение, запись и очистка проверены пользователем на TYT MD-9600 с OpenGD77.

## v0.6.0 — локальный редактор

После чтения MD-9600 откройте канал, контакт или зону и нажмите «Изменить».
В разделе «DMR ID и позывной» доступна отдельная кнопка «Изменить».
Редактируются существующие записи: общие параметры каналов и FM/DMR,
DMR ID/позывной, контакты DMR/DTMF, имена и состав зон (до 80 каналов).
Добавление/удаление записей, правка VFO, APRS, координат, списков групп и
сканирования пока не реализованы. Остальные разделы доступны для просмотра.

Каждая принятая правка атомарно сохраняется в приватном каталоге приложения.
«Проект» позволяет экспортировать/импортировать `.ogcproj`, отменять последние
20 операций текущей сессии, восстановить исходное чтение и видеть число
изменённых байтов по блокам. Исходная и рабочая копии входят в файл проекта;
контрольная сумма и размеры блоков проверяются при открытии.
`.ogcproj` — собственный формат Android-редактора, не `.ogd` Windows CPS.
Экспортируйте проект за пределы приложения перед его удалением.

Редактор не отправляет изменения в радиостанцию. Существующий отдельный модуль
обновления спутников не связан с проектом codeplug. Неизменённые поля и
неизвестные биты сохраняются в исходном виде. В интерфейсе скрывается неактивный
блок FM/DMR; его байты сохраняются при переключении режима.

## v0.7.1 — создание отсутствующего блока спутников

Если заголовок OpenGD77 v1 корректен, цепочка TLV заканчивается FF/FF,
а оставшаяся часть прочитанной области 0x2000 полностью стёрта, обновление
может создать Satellite TLV ID 3 из Satellites.txt и пригодных TLE.
Перед записью показан отдельный запрос создания списка; backup, повторное
чтение и полный read-back остаются обязательными. За новым блоком сохраняется
стёртый терминатор. При повреждённой цепочке, неизвестных данных в хвосте
или недостатке места запись запрещена. Существующий спутниковый блок по-прежнему
обновляется только по орбитальным байтам, без изменения состава и частот.
Исправление воспроизводит структуру проекта MD9600-20260930-153401: блоки
1/0x400 и 2/0x200, затем стёртая память с +0x61C. Новый блок заканчивается
на +0xFFB, поэтому для этого образа меняется только FLASH-сектор 0x20.


## v0.8.0 — база позывных DMR

- Отдельный экран «База позывных DMR» на главном экране.
- Загрузка официального RadioID CSV по HTTPS, импорт CSV UTF-8/Windows-1251,
  сохранение последнего исходного CSV для повторной фильтрации без сети.
- Фильтр по одному или нескольким префиксам ID (по умолчанию 401),
  имя/фамилия/город/область/страна, разделитель пробел/точка, 16–48 символов.
  По умолчанию выбрано 48 символов; полный текст остаётся в предпросмотре,
  а возможная обрезка радиополя явно показана стрелкой.
- Предпросмотр именно записываемого текста и поиск; показаны до 200 совпадений,
  запись использует весь подготовленный список. Кириллица транслитерируется,
  диакритика удаляется, остальные неподдерживаемые знаки становятся точками.
- ID сортируются, повторные ID объединяются (остаётся первая строка),
  некорректные строки подсчитываются, переполнение запрещено.
- Замена или явная очистка базы с отдельным подтверждением. Проверяется модель MD-9600, Radio Info v3/v4 и идентификатор FLASH 16 МБ
  0x4018, если прошивка его сообщает. Обычный маркер отсутствующих полей
  RUS v4 принимается с ограничением записи двумя документированными диапазонами.
- Перед записью сохраняется ZIP всех затрагиваемых секторов (до/после),
  доступен экспорт предыдущих резервных копий. Повторное чтение до записи,
  проверка каждого записанного сектора. При записи нескольких секторов
  заголовок временно отключается и публикуется последним; затем перезагрузка.
- Изменения codeplug, спутники и голосовые подсказки не входят в план записи.

Формат, границы и источники: docs/CALLSIGN_DATABASE.md. На MD-9600 пользователем
проверены загрузка базы, чтение из рации, запись и очистка. Создание/обновление
спутников v0.7.1 и редактирование codeplug также подтверждены пользователем.


## v0.8.9 — компактный редактор и жесты каналов

Пользователь подтвердил работу функций этапа 5 в 0.8.8.

- В шапке редактора остались «Назад», «Поиск», «Действия»; название текущего раздела находится под ними. Дерево верхней кнопки удалено, возврат по уровням сохранён.
- База позывных открывается с главного экрана, дублирующий пункт в «Действия» удалён. Сведения о проекте объединены со сведениями о станции.
- Добавление позывных использует отдельные поля DMR ID, позывной, имя, город, область, страна с предпросмотром строки для рации. CSV сохраняет границы выбранных полей в подготовленной базе. Из рации считывается только объединённая строка, поэтому существующие записи такого источника редактируются целиком без угадывания границ.
- В списке каналов удержание включает выделение. Нажатия отмечают каналы, «Действия» позволяет массово изменить, добавить в зону, удалить, выбрать все или завершить выделение. «Назад» сначала закрывает выделение.
- В составе зоны нажатия выделяют каналы, удержание и движение меняют порядок одного канала или выделенной группы. У края списка работает прокрутка. «К позиции…» переносит без последовательных нажатий вверх/вниз; «Убрать выбранные» удаляет только из зоны. Правки состава зоны применяются после сохранения и предварительного просмотра и отменяются одним шагом.

Физические номера каналов сохраняются: перетаскивание меняет порядок в зоне, а не ссылки на записи codeplug. Пользователь подтвердил работу версии 0.8.9.


## v0.8.10 — меню разделов, серии каналов и изображение заставки

0.8.9 проверена пользователем. Журнал убран с главной страницы; доступен только в инструментах спутников.

«Действия» зависит от раздела: «Обзор»/«Радиостанция» открывают «Проект», «Каналы» — «Каналы и зоны», контакты — добавление DMR/DTMF/групп и переход к их спискам, APRS/спутники — список, редактирование конфигураций, Keps/TLE и APRS. Запись — последний пункт меню.

Кнопка добавления каналов предлагает единичный канал или серию. Серия использует общую форму настроек канала с полями количества и шага серии (0, 2.5, 5, 6.25, 10, 12.5, 25, 30, 50 кГц). Шаг серии задаёт разность частот соседних каналов; шаг настройки частоты канала остаётся отдельным параметром. Все каналы создаются одной отменяемой операцией с предпросмотром.

Выбранные каналы можно добавить в новую зону. Выделение завершается пунктом «Отменить выделение». В списках добавления каналов в зону есть «Выбрать все», лимит 80 проверяется перед применением.

Заставка: выбор PNG/JPEG или другого поддерживаемого Android изображения, преобразование в 128×64 монохром с сохранением пропорций и белыми полями, предпросмотр. Изображение записывается TLV ID 1 в дополнительных настройках 0x20000 вместе с разделом «Загрузочный экран». Остальные TLV/спутники/мелодия сохраняются; повреждённые данные или нехватка места отклоняются. При выборе изображения строки текста скрыты. Форма добавляет изображение сначала в проект, передача в рацию выполняется отдельно с резервной копией и read-back.

Формат подтверждён исходниками [OpenGD77 UC1701](https://github.com/ajorg/OpenGD77/blob/master/firmware/source/hardware/UC1701.c), [uiSplashScreen](https://github.com/ajorg/OpenGD77/blob/master/firmware/source/user_interface/uiSplashScreen.c) и [qDMR AdditionalSettingsElement](https://github.com/hmatuschek/qdmr/blob/master/lib/opengd77base_codeplug.hh). Пользователь подтвердил загрузку заставки и работу версии 0.8.10.

Конфигурации спутников теперь редактируются полями NORAD, имя, частоты, субтоны и APRS, хранятся на телефоне и используются при следующем обновлении Keps. Это список для обновления: NORAD отсутствует в 100-байтной записи рации, поэтому конфигурация не восстанавливается из считанного проекта. После изменения конфигурации требуется загрузить TLE. Перед записью показывается подготовленный результат, непригодные TLE пропускаются прежними проверками. TX3 сохраняется в конфигурации, но проверенный формат записи рации не содержит TX3.
