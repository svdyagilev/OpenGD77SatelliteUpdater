## Сборки

[GitHub Releases](https://github.com/svdyagilev/OpenGD77SatelliteUpdater/releases) сохраняет APK и SHA-256 постоянно. Публикация выполняется только после успешных unit-тестов и сборки. Debug APK предназначены для ручной установки. Сборка GitHub использует стандартный debug-ключ среды CI; APK из разных сред могут потребовать переустановки, поэтому сначала экспортируйте проекты.

Артефакты [Actions](https://github.com/svdyagilev/OpenGD77SatelliteUpdater/actions) хранятся 30 дней и не служат постоянным архивом. Существующий Release не перезаписывается: исправленная сборка получает новую версию или следующий номер rc.

## Правила

1. `main` содержит принятую версию; новые функции проходят отдельный PR. После подтверждения испытаний кандидат включается в `main`.
2. `versionName` и `versionCode` меняются вместе; code только увеличивается. Документация различает автоматическую и аппаратную проверку.
3. Release-теги, сохранённые снимки и история не переписываются и не удаляются.
4. Для 0.8.11 Master-мощность и шумоподавитель доступны только для чтения. Запись не реализована. Формат сохранённых проектов 2 открывается версией 0.8.11 и новее; старые проекты формата 1 читаются.
