# Таблица каналов CSV (v0.8.7)

Меню редактора **⋮ → Инструменты каналов и зон** содержит импорт и экспорт.
Файл — UTF-8 (BOM допускается), разделитель `;` или `,`, стандартные двойные кавычки. Экспорт использует `;` и кавычки вокруг всех полей.

Импорт всегда добавляет каналы в свободные физические места. Он не заменяет существующие записи и не создаёт зоны, контакты, группы или APRS. `source_index` — справочный номер из экспорта, не целевой слот. Повторный импорт создаёт новые копии; имена каналов могут повторяться.

Обязательный минимальный файл:

```csv
name;rx_mhz;tx_mhz;mode
Локальный;145.500000;145.500000;FM
Репитер;433.500000;434.100000;DMR
```

Частоты — МГц с точностью до 10 Гц. Десятичная запятая допускается; при разделителе `,` такое поле нужно заключить в кавычки. Режим — `FM` или `DMR`. Пустые необязательные поля используют значения нового канала: общая мощность, выключенные субтоны, CC1, TS1.

Дополнительные столбцы:

| Столбцы | Значения |
|---|---|
| `source_index` | Справочный номер, при импорте игнорируется |
| `power` | 0: общая; 1–10: 100 мВт, 250 мВт, 500 мВт, 750 мВт, 1 Вт, 5 Вт, 10 Вт, 25 Вт, 40 Вт, +Вт− |
| `tot_seconds` | 0–495, шаг 15; 0 — выключен |
| `step_index` | 0–7: 2.5, 5, 6.25, 10, 12.5, 25, 30, 50 кГц |
| `rx_only`, `beep`, `eco`, `vox`, `zone_skip`, `all_skip`, `fast`, `priority`, `location` | 0/1 |
| `latitude`, `longitude` | Градусы с десятичной точкой/запятой |
| `rx_tone`, `tx_tone` | Только FM: `нет`, `CTCSS 88.5 Гц`, `DCS 023 N`, `DCS 023 I` |
| `wide` | Только FM: 0 — 12.5 кГц, 1 — 25 кГц |
| `squelch` | Только FM: 0 — общий, 1–21 — уровни редактора |
| `aprs_index` | Только FM: 0 — нет; 1–8 — существующая запись APRS |
| `color_code`, `timeslot` | Только DMR: 0–15; 1/2 |
| `contact_index`, `rx_group_index` | Только DMR: 0 — нет; номер существующего контакта/группы в текущем проекте |
| `dmr_id` | Только DMR: 0 — общий ID; 1–16777215 — ID канала |
| `dmo`, `roaming` | Только DMR: 0/1 |
| `ta_ts1`, `ta_ts2` | Только DMR: 0–3, значения редактора алиаса |

Неизвестные или повторные столбцы, неверные значения, несуществующие ссылки и нехватка мест отменяют импорт целиком. Перед применением показывается количество новых записей и изменённых байтов. Вся операция отменяется одним шагом в меню проекта. Импорт/экспорт ограничен поддерживаемыми полями редактора, не переносит скрытые/неподдерживаемые параметры и не является обменом двоичным Windows codeplug `.ogd`.

Копирование и серия по шаблону сохраняют исходную запись полностью. Если исходник содержит значения, не поддерживаемые проверкой новых записей, операция отклоняется до применения, без их молчаливого сброса.
