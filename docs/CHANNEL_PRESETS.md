# Channel presets

**Действия → Предустановленные каналы** or **Добавить → Предустановленные каналы** offers:

| Plan | Channels | First / last MHz | Spacing | FM bandwidth |
|---|---:|---|---|---|
| LPD433 | 69 | 433.075 / 434.775 | 25 kHz | 25 kHz |
| PMR446 | 16 | 446.00625 / 446.19375 | 12.5 kHz | 12.5 kHz |
| FRS (USA) | 22 | FCC channel ordering | 25 kHz within each subrange | 12.5 kHz |

FRS 1–7: 462.5625…462.7125; 8–14: 467.5625…467.7125; 15–22: 462.5500…462.7250 MHz. The first two bands are not concatenated into a linear frequency series.

Sources: [Midland LPD](https://support.midlandeurope.com/media/manual/d/e/e/b/deeb04a16fe8979beba2952bde101bc86af7d5c9_Channels_G9_G9E_PLUS.pdf), [Midland PMR446](https://support.midlandeurope.com/media/manual/3/3/b/d/33bde692440e88d846d431ce4c696fafb3c13b85_channel_list_G11_PRO.pdf), [FCC FRS §95.563](https://docs.fcc.gov/public/attachments/FCC-17-57A1_Rcd.pdf).

Choose individual channels, power, receive-only, and a new/existing zone. All channels use simplex RX=TX and no tones. Duplicate matching uses FM and identical RX/TX; existing channel settings are not changed. Zone capacity, references and free slots are checked before applying. Custom series and template series remain available separately.

The plans are frequency references, not a declaration that a given radio or transmission mode is authorized for a service.
