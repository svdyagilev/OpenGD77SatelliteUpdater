# Этап 5 — проекты и запись (v0.8.8)

## Что уже было в 0.8.7

Выбор разделов записи, подсчёт изменённых байтов, запрет новых потерянных ссылок, проверка совпадения рации с исходным чтением, резервирование затрагиваемых FLASH-секторов, проверка результата чтением. Было одно автосохранение проекта и до 20 шагов отмены в памяти текущей сессии. Экспорт ZIP резервной копии был доступен, восстановление — нет.

Пользователь подтвердил успешные испытания 0.8.7.

## Что добавлено

В редакторе откройте **⋮ → Проект**:

- **Список изменений проекта** сравнивает исходное чтение с рабочей копией.
- **Сравнить с другим проектом** сравнивает рабочие копии текущего и выбранного `.ogcproj`. Различие модели/прошивки явно показывается. Сравнение ничего не изменяет.
- **Проверить проект** показывает ошибки ссылок, пустые зоны и повторные ID/TG контактов. Пустые зоны и одинаковый ID у нескольких контактов могут быть намеренными, поэтому являются предупреждениями. Ссылки, отсутствовавшие уже в исходном чтении, также показаны как предупреждения; новые потерянные ссылки блокируют запись.
- **История версий** содержит последние 30 ревизий, автоматически сохранённых после чтения, изменения или открытия проекта. Сохраняются полные снимки с контрольной суммой. История охватывает все проекты в приложении; в карточке выбранной версии показан позывной станции. Старейшие версии сверх лимита удаляются. Нужные версии можно экспортировать. История начинается с текущего проекта после установки 0.8.8; прошлые состояния до этого момента не реконструируются.
- **Восстановить из резервной копии** выбирает ZIP из локальных копий записи codeplug или из файлов телефона.

В каждом списке изменений нажмите запись для просмотра полей до/после. Неотображаемые параметры и служебные области отмечаются отдельным сообщением с количеством изменённых байтов.

На экране записи кнопка **Что будет записано** сравнивает исходную память с результатом только выбранных разделов. Невыбранные изменения не включаются в список и остаются в рабочем проекте. Кнопка **Проверить** проверяет этот же результат; проверка повторяется перед подтверждением записи.

## Восстановление

ZIP должен содержать согласованные `before.ogcproj` и `after.ogcproj` с корректными контрольными суммами. Копии базы позывных и отдельные `.bin` спутников не относятся к этому восстановлению. Архивы ограничены по размеру/числу записей, файлы из них не извлекаются в файловую систему.

Приложение определяет байты, действительно затронутые записью в архиве, и готовит их возврат к значениям до той записи. Байты, которые запись не меняла, включая неотправленные правки, остаются в текущем проекте. Предварительный просмотр показывает получившиеся изменения; операция отменяется одним шагом.

Модель, формат и прошивка архива должны совпадать с текущим проектом. Все ограничения поддерживаемых полей и ссылок остаются действующими: восстановление неподдерживаемых изменений отклоняется, без обхода проверки.

Данные восстанавливаются сначала в проект на телефоне. Для передачи в станцию используйте обычный экран записи. Если прежняя запись прервалась, сначала заново прочитайте актуальную рацию; восстановление не снимает журнал блокировки и не запускает автоматическую запись. Открытие исторической версии сохраняет её прежнюю базовую память, поэтому проверка перед записью может потребовать перечитать станцию.
