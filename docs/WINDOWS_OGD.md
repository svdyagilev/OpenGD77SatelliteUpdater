# Windows OGD: historical feature

Import/export of Windows OGD was removed in v0.8.13 at the user's request. It is no longer available in the application.

Projects `.ogcproj` in formats 1 and 2 remain supported. The embedded Windows template from projects saved with v0.8.11/v0.8.12 is retained as compatibility data; it does not enable OGD import/export. CSV, native projects, history and write backups are unaffected.
